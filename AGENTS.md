# Instrucciones para trabajar en CadvoSalud

- Proyecto educativo independiente; no copiar código ni asumir arquitectura de TecBot.
- Comunicación y documentación en español. Trabajar dentro de esta carpeta y respetar los cambios del usuario.
- Solo datos ficticios de pacientes, médicos y citas. No usar datos médicos reales ni presentar esta aplicación como lista para producción.
- El selector de perfil es una demostración, no autenticación ni control de acceso. No afirmar que protege información.
- Directorio CLUES: conservar fuente y fecha de corte, distinguir datos públicos de disponibilidad y reservas ficticias, y no afirmar afiliaciones.
- La ubicación debe ser opcional; documentar qué se envía y evitar registrar coordenadas en despliegues reales.
- Para IA futura, responder solo con documentos autorizados, citar fuentes, abstenerse sin evidencia y no dar diagnósticos ni atención de emergencias.
- En Windows usar `py` y `npm.cmd` cuando corresponda. Antes de finalizar, ejecutar las pruebas pertinentes y describir limitaciones.
- No borrar bases de datos, archivos descargados o cambios ajenos sin autorización explícita.
