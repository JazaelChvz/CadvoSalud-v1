# Documentos de demostración

Esta carpeta contiene únicamente material ficticio para el curso. No representa información oficial de hospitales ni instrucciones médicas. El chat busca secciones de estos documentos y usa Ollama local para redactar una respuesta, mostrando su fuente. La IA puede equivocarse y la búsqueda por palabras puede no encontrar información existente.

No agregar datos reales de pacientes ni información confidencial.
